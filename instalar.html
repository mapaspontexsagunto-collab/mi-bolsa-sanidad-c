Instalar marcador «Capturar bolsa»

Es un marcador que lee la tabla que tú ya has abierto en la web oficial tras resolver el CAPTCHA. No hace peticiones a ningún sitio.

  1. Pulsa Copiar código.
  2. Guarda cualquier página como marcador (Safari: Compartir → Añadir marcador; Chrome: ⭐).
  3. Edita el marcador: nombre «Capturar bolsa» y, en la dirección, pega el código.
  4. En la web oficial, con el listado visible, abre el marcador (Safari: Marcadores; Chrome Android: escribe «Capturar» en la barra y elígelo).
